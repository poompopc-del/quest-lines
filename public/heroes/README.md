# รูปตัวละคร (heroes)

วางไฟล์รูปฮีโร่ของคุณในโฟลเดอร์นี้ แล้วเปิด `public/index.html` ค้นหาคำว่า `const HERO_IMG = {`
แล้วเพิ่มบรรทัดของตัวที่ต้องการ เช่น

```js
const HERO_IMG = {
  pip:     { src:'heroes/pip.png', h:160 },
  mira:    { src:'heroes/mira.png', h:165 },
  boomtos: { src:'heroes/boomtos.png', h:185, flip:true },
};
```

ตัวที่ไม่ได้ใส่ไว้จะยังใช้ภาพวาดด้วยโค้ดแบบเดิม ค่อยๆ เปลี่ยนทีละตัวได้

## ชื่อตัวละคร (ใช้เป็นชื่อหน้า `:`)
pip · mira · rook · bastion · luma · bruna · kiko · boomtos · puff

## รูปที่ใช้ได้ดี
- **PNG พื้นหลังโปร่งใส** (หรือ WebP/SVG ก็ได้)
- **เต็มตัว** เท้าอยู่ชิดขอบล่างของรูป ไม่มีพื้นที่ว่างด้านล่างมาก
- **หันหน้าไปทางขวา** (ถ้าหันซ้าย ใส่ `flip:true`)
- ขนาดแนะนำ: สูง 512–1024 px (ไฟล์ไม่ควรเกิน ~300 KB เพื่อให้มือถือโหลดเร็ว)
- ทุกตัวควรใช้สไตล์และมุมกล้องเดียวกัน จะดูเป็นเกมเดียวกัน

## ค่าที่ปรับได้
| ค่า | ความหมาย |
|---|---|
| `h` | ความสูงในเกม (ภาพเดิมประมาณ 150–175) |
| `flip` | `true` = กลับด้านซ้าย-ขวา |
| `dx`, `dy` | เลื่อนภาพ (บวก = ขวา / ลง) ถ้าเท้าลอยหรือจมพื้น |
| `face` | ครอปหน้าในไอคอน HP มุมซ้ายบน รูปแบบ `'x y กว้าง สูง'` ถ้าหน้าไม่อยู่ตรงกลาง |

## ข้อควรรู้
- ตัวที่ใช้รูปยังมีแอนิเมชันหายใจ พุ่งโจมตี กระพริบแดงตอนโดนตี กระโดดดีใจ และล้มตอนแพ้ครบ
  แต่**แขนเหวี่ยงดาบ กระพริบตา และขาเดิน**จะไม่ขยับ เพราะรูปเป็นชิ้นเดียว
- **อาวุธและชุดเกราะที่ใส่จะไม่แสดงบนตัว** (ค่าพลังยังได้ตามปกติ) ถ้าอยากให้เห็นอาวุธ ให้วาดไว้ในรูปเลย
- เปลี่ยนรูปแล้วในมือถือยังเห็นรูปเก่า → ใน index.html เพิ่มเลข `HERO_IMG_VER` ทีละ 1

## แบบหลายท่า (สไปรต์ชีต) — แบบที่ Plink และ Puff ใช้
ค้นหา `const HERO_SPRITE = {` ใน index.html
- ชีต 1 ไฟล์ แต่ละแถวคือ 1 ท่า ทุกช่องกว้าง `cw` สูง `ch` เท่ากัน ตัวละครยืนตรงกลางช่อง (ตำแหน่ง `ax`) เท้าชิดขอบล่าง
- `anims` บอกว่าท่าไหนอยู่แถวไหน มีกี่รูป และเล่นกี่วินาที: idle (ยืน), attack, hurt, dead, cheer, walk
- ตัวอย่าง: `heroes/plink/` = ท่าละ 1 ไฟล์ สูง 73 px · ขยาย `scale:3`

## Puff (ก้อนชมพู) — โฟลเดอร์ `heroes/puff/`
ตัดจากสไปรต์ชีตทีละท่า จัดเท้าให้ชิดขอบล่าง และลบพื้นหลังออกแล้ว
- idle 9 รูป · walk 8 · hurt 5 · dead 9 · atk1 ตบรัว 17 · atk2 กระโดดทับ 9 · atk3 กลิ้งพุ่งชน 16 · fin ดาวตกพิฆาต 14
- ช่องสูง `ch:45` ขยาย `scale:5.5` (ปรับขนาดในเกมได้ที่ค่า scale ใน `HERO_SPRITE.puff`)

## Boomtos — โฟลเดอร์ `heroes/boomtos/`
- ท่าโจมตี (atk1–3) และท่าไม้ตาย (fin) รวมเปลวไฟจากแถวเอฟเฟกต์ของชีตไว้ในรูปแล้ว
- ท่าไม้ตายเล่นตอนสะกด BOOM เท่านั้น (`finMin:99`)
