# Quest Lines v2 — RPG ฝึกคำศัพท์ภาษาอังกฤษ ⚔️

เกมเว็บสไตล์พิกเซลอาร์เคนสำหรับคนไทยฝึกภาษาอังกฤษ ไฟล์เกมเดียว (`public/index.html`) + ฟังก์ชันเซิร์ฟเวอร์เล็กๆ 1 ตัว
**v2 เล่นได้ครบทุกระบบแม้ไม่มี API key** — มีเนื้อหาในตัว และจะเปิดโหมด AI (Claude) ให้อัตโนมัติเมื่อเซิร์ฟเวอร์ตั้งค่าคีย์ไว้

## ระบบในเกม

| ระบบ | รายละเอียด |
|---|---|
| 🗼 Monster Tower | ตอบคำศัพท์เพื่อโจมตี มอนสเตอร์พิกเซลสุ่มไม่ซ้ำ บอสทุก 5 ชั้น เช็กพอยต์ จับเวลา 20 วิ คอมโบ/คริติคอล/ตอบไวแรงขึ้น |
| ⚔️ อาชีพ + สกิล | นักรบ (Iron Wall) · จอมเวท (Arcane Blast) · นักฆ่าเงา (Shadow Step) + Insight ตัดตัวเลือกผิด |
| 🧪 ไอเทม / อัปเกรด | ยาฟื้นพลัง, น้ำมนตรา, คัมภีร์สัจจะ, อัปเกรด HP/ATK/MP ถาวร, ร่างฮีโร่ |
| 📖 Story | 3 การผจญภัยในตัว (แฟนตาซี / สืบสวน / เอาชีวิตรอด) ภาพฉากพิกเซล 19 ฉากจบ พิมพ์ตอบเองเป็นภาษาอังกฤษได้ มีตรวจแกรมม่าเบื้องต้นเป็นภาษาไทย |

คีย์ลัดบนคอม: `1`–`4` เลือกคำตอบ · `Enter` ไปข้อต่อไป · เนื้อเรื่องกด `A/B/C` · `Esc` ปิดหน้าต่าง

## โครงสร้างไฟล์

```
quest-lines-app/
├── public/
│   ├── index.html          ← ตัวเกมทั้งหมด (HTML+CSS+JS ไฟล์เดียว)
│   ├── manifest.json       ← ข้อมูล PWA
│   ├── service-worker.js   ← แคชไว้เล่นออฟไลน์
│   └── icons/
├── api/claude.js           ← เรียก Claude API ฝั่งเซิร์ฟเวอร์ (เก็บ API key)
├── server.mjs              ← เซิร์ฟเวอร์ทดสอบในเครื่อง (npm start)
├── package.json
└── .env.example
```

## เล่นในเครื่องทันที

ต้องมี Node.js 18 ขึ้นไป

```bash
cd quest-lines-app
npm start            # เปิด http://localhost:3000
```

ไม่ต้อง `npm install` อะไรเลย ถ้าอยากลองโหมด AI ให้คัดลอก `.env.example` เป็น `.env` แล้วใส่ `ANTHROPIC_API_KEY=sk-ant-...`
(เปิด `public/index.html` ตรงๆ ก็เล่นได้ แต่จะเป็นโหมดออฟไลน์และไม่มี PWA)

## โหมดออฟไลน์ vs โหมด AI

- เกมเช็ก `GET /api/claude` ตอนเปิด ถ้าเซิร์ฟเวอร์มีคีย์ จะขึ้น "AI พร้อม" ในหน้าตั้งค่า
- **อัตโนมัติ** (ค่าเริ่มต้น): ใช้ AI ถ้าพร้อม ไม่พร้อมก็ใช้เนื้อหาในเครื่อง — ตอนสู้ AI จะเตรียมคำถามและมอนสเตอร์พิกเซลตัวใหม่มาให้เบื้องหลัง
- **ออฟไลน์**: ไม่เรียก API เลย (ประหยัด) · **AI เท่านั้น**: บังคับใช้ AI
- ถ้า AI ล่ม/ช้า เกมจะแจ้งเป็นภาษาไทยและยังเล่นต่อได้

## ขั้นตอนที่ 1: ขอ Anthropic API Key (ไม่บังคับ — เฉพาะโหมด AI)

1. ไปที่ https://console.anthropic.com/settings/keys
2. กด "Create Key" แล้วคัดลอกคีย์ (ขึ้นต้นด้วย `sk-ant-...`)
3. **ห้าม** ใส่คีย์ใน `public/index.html` ใส่เฉพาะ environment variable ของเซิร์ฟเวอร์

## ขั้นตอนที่ 2: Deploy ขึ้น Vercel

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo (หรือใช้ `npx vercel` ในโฟลเดอร์นี้)
2. Vercel → New Project → เลือก repo → Framework: Other → กด Deploy (Output Directory: `public`)
3. ถ้าจะใช้ AI: Project Settings → Environment Variables → เพิ่ม `ANTHROPIC_API_KEY` แล้วกด Redeploy
4. ได้ลิงก์ เช่น `https://quest-lines-yourname.vercel.app` เปิดเล่นได้เลย

## ขั้นตอนที่ 3: ติดตั้งเป็น "แอป" บนมือถือ (ทำได้ทันที ไม่ต้องขึ้น App Store)

หลัง deploy เสร็จ เปิดลิงก์เว็บของคุณบนมือถือ:

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "Add to Home screen" / "ติดตั้งแอป" → จะได้ไอคอนแอปจริงบนหน้าจอ เปิดแบบเต็มจอไม่มีแถบ URL
- **iPhone (Safari):** เปิดลิงก์ → กดปุ่มแชร์ 🔗 → "Add to Home Screen" → ได้ไอคอนแอปเช่นกัน

นี่คือ **Progressive Web App (PWA)** — ใช้งานเหมือนแอปจริง มีไอคอน เปิดเต็มจอ เก็บข้อมูล (เลเวล/ทอง/คำศัพท์) ในเครื่องได้ และเปิดได้แม้เน็ตไม่เสถียร (v2 เล่นได้ครบแม้ไม่มีเน็ต มีแค่โหมด AI ที่ต้องใช้เน็ต)

## ขั้นตอนที่ 4 (ถ้าอยากได้ไฟล์ .apk / ขึ้น Google Play หรือ App Store จริงๆ)

โปรเจกต์นี้พร้อมสำหรับสองทางเลือกนี้:

**ทางเลือก A — PWABuilder (ง่ายที่สุด สำหรับ Android):**
1. ไปที่ https://www.pwabuilder.com
2. ใส่ลิงก์เว็บที่ deploy ไว้ (จากขั้นตอนที่ 2)
3. กด "Package for Stores" → เลือก Android → ดาวน์โหลดไฟล์ `.aab`/`.apk` → อัปโหลดขึ้น Google Play Console (ต้องสมัครบัญชีนักพัฒนา ค่าธรรมเนียมครั้งเดียวประมาณ $25)
4. สำหรับ iOS จะได้โปรเจกต์ Xcode ไปเปิดต่อบน Mac (ต้องมีบัญชี Apple Developer ปีละ $99)

**ทางเลือก B — Capacitor (ถ้าอยากคุมโค้ด native เพิ่มเติมเอง):**
```bash
npm install @capacitor/core @capacitor/cli
npx cap init "Quest Lines" "com.yourname.questlines"
npx cap add android   # ต้องมี Android Studio
npx cap add ios        # ต้องมี Xcode (Mac เท่านั้น)
npx cap copy
npx cap open android   # หรือ ios
```
จากนั้น build/run จาก Android Studio หรือ Xcode ตามปกติ แล้วอัปโหลดขึ้นสโตร์

## หมายเหตุด้านความปลอดภัย

- API key อยู่ในไฟล์ `api/claude.js` ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่ถูกส่งไปหน้าเว็บ ปลอดภัยต่อการเผยแพร่แอปสาธารณะ
- `api/claude.js` มี rate-limit แบบง่ายในตัว (30 ครั้ง/นาที/IP ต่อ instance) ถ้าเปิดให้คนเยอะๆ เล่น ควรเพิ่มระบบจำกัดที่แข็งแรงกว่า (เช่น Vercel KV / Upstash) และตั้ง usage limit ใน Anthropic Console
- ข้อมูลผู้เล่น (เลเวล/ทอง/คำศัพท์/ความสำเร็จ) เก็บด้วย `localStorage` (คีย์ `questlines_save_v2` — เซฟจาก v1 ย้ายมาให้อัตโนมัติ) ในเครื่องผู้เล่นแต่ละคน ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ ถ้าอยากทำระบบบัญชีผู้ใช้ข้ามเครื่อง จะต้องเพิ่มฐานข้อมูลเอง (เช่น Supabase, Firebase)
- ย้ายเซฟข้ามเครื่องได้เองที่ ตั้งค่า → คัดลอกรหัสเซฟ / นำเข้ารหัสเซฟ
