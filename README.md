# ⚔️ Quest Lines — Word Battle

เกมสะกดคำภาษาอังกฤษสู้มอนสเตอร์ สไตล์การ์ตูน — แตะตัวอักษรให้เป็นคำ ยิ่งคำยาว ยิ่งแรง!
เล่นฟรี ไม่มีค่าใช้จ่าย ไม่ต้องใช้ API และเล่นออฟไลน์ได้ (ติดตั้งเป็นแอปบนมือถือได้)

## วิธีเล่น
- แตะตัวอักษร 15 ช่องเพื่อสะกดคำภาษาอังกฤษ (3 ตัวขึ้นไป) แล้วกดปุ่มดาบเพื่อโจมตี
- ตัวอักษรหายาก (จุดสีเทา/ทอง/แดง) ให้พลังมากกว่า คำยาวได้ตัวคูณดาเมจ
- มอนสเตอร์โจมตีกลับหลังทุกคำ — ดูจุดอ่อน/ความสามารถของมันในกล่องสีเขียว
- ปุ่มสลับ 🔄 เปลี่ยนตัวอักษร (เสียเทิร์น) · 💡 คำใบ้ 3 ครั้ง/ด่าน
- ยาแดงฟื้น HP 50% · ยาม่วงทำให้คำถัดไปแรง x2 (ไม่เสียเทิร์น)
- อัญมณีบนตัวอักษร: 🪙 ได้ทอง · ❤️ ฟื้น HP · 💎 ดาเมจ +50%
- คำศัพท์เป้าหมาย ⭐ ได้ดาเมจ +50% และแสดงความหมายภาษาไทย บันทึกลงสมุดคำศัพท์
- คำยาว 4 ตัวขึ้นไปมีออร่า (ยิ่งยาวยิ่งเท่) และเสียงเวทมนตร์ไล่ระดับ
- คำธาตุ 9 แบบ (FIRE, ICE, STORM, WATER, POISON, WIND, ROCK, LIGHT, DARK ฯลฯ) มีคัตซีนมอบพลังให้อาวุธ: ติดไฟ แช่แข็ง ฟ้าผ่าซ้ำ ล้างหิน+ฮีล พิษ หลบหลีก ผิวหิน ฮีล ดูดเลือด
- คำหยาบใช้ได้ 🤬 ดาเมจ x2 แต่สะท้อนเข้าตัวเอง 30% ของ HP — so rude!
- คีย์บอร์ด: พิมพ์ตัวอักษร · Backspace ลบ · Enter โจมตี · Space สลับ · Esc หยุด

## ระบบในเกม
- 5 บท × 8 ด่าน (สุสานเหรียญทอง / โพรงตะไคร่ / ถ้ำน้ำแข็ง / ป้อมเปลวเพลิง / สุสานจอมเวทมรณะ) พร้อมบอสท้ายบท
- มอนสเตอร์ 20 แบบ + บอส 5 ตัว (บอสบทที่ 5: Necromancer ร่ายลูกไฟวิญญาณ) แต่ละตัวมีความสามารถต่างกัน (จุดอ่อนตัวอักษร, เกราะ, ดูดเลือด, สาปหิน, ฟื้นตัว, ชาร์จพลัง)
- ร้านค้า: ตัวละคร 7 ตัว แต่ละตัวมีสกิลเฉพาะ (Pip, Mira, Rook, Sir Bastion, Luma, Bruna, Kiko), อาวุธ 7 ชิ้น, ชุดเกราะ 4 ชุด, ไอเทมเสริม 8 ชิ้น (ใส่ได้ 2 ช่อง), ยา, อัปเกรด HP
- อาวุธและชุดเกราะที่ใส่แสดงบนตัวละคร
- แอนิเมชันโจมตี/โดนโจมตี/ตาย, ตัวละครหายใจ กะพริบตา, เดินผ่านฉากไปยังศัตรูตัวถัดไป
- พจนานุกรมภาษาอังกฤษในตัวกว่า 100,000 คำ ใช้ได้โดยไม่ต้องต่อเน็ต
- บันทึกเกมในเครื่องอัตโนมัติ, ย้ายเซฟข้ามเครื่องได้ด้วยรหัสในหน้าตั้งค่า

## รันในเครื่อง
```bash
npm start
```
แล้วเปิด http://localhost:3000 (หรือดับเบิลคลิก `public/index.html` ก็เล่นได้)

## Deploy บน Vercel
1. Push โปรเจกต์ขึ้น GitHub
2. ใน Vercel → Add New Project → เลือก repo
3. Framework Preset: **Other** · Output Directory: **public** (มี `vercel.json` ตั้งไว้ให้แล้ว)
4. ไม่ต้องตั้ง Environment Variables
5. ทุกครั้งที่ `git push` Vercel จะ deploy ใหม่อัตโนมัติ

## โครงสร้าง
```
public/
  index.html          เกมทั้งหมด (HTML + CSS + JS + พจนานุกรม ในไฟล์เดียว)
  manifest.json       ตั้งค่า PWA
  service-worker.js   แคชให้เล่นออฟไลน์
  icons/              ไอคอนแอป
server.mjs            เซิร์ฟเวอร์ static สำหรับรันในเครื่อง
```
