# ⚔️ Quest Lines 2.0 — Word Battle RPG

เกมสะกดคำภาษาอังกฤษสู้มอนสเตอร์ สไตล์การ์ตูน — แตะตัวอักษรให้เป็นคำ ยิ่งคำยาว ยิ่งแรง!
เล่นฟรี ไม่มีค่าใช้จ่าย ไม่ต้องใช้ API และเล่นออฟไลน์ได้ (ติดตั้งเป็นแอปบนมือถือได้)

## วิธีเล่น
- แตะตัวอักษร 15 ช่องเพื่อสะกดคำภาษาอังกฤษ (3 ตัวขึ้นไป) แล้วกดปุ่มดาบเพื่อโจมตี
- ตัวอักษรหายาก (จุดสีเทา/ทอง/แดง) ให้พลังมากกว่า คำยาวได้ตัวคูณดาเมจ
- มอนสเตอร์โจมตีกลับหลังทุกคำ — ดูจุดอ่อน/ความสามารถของมันในกล่องสีเขียว
- ปุ่มสลับ 🔄 เปลี่ยนตัวอักษร (เสียเทิร์น) · 💡 คำใบ้ 3 ครั้ง/ด่าน
- ยาแดงฟื้น HP 50% · ยาม่วงทำให้คำถัดไปแรง x2 (ไม่เสียเทิร์น)
- อัญมณีบนตัวอักษร: 🪙 ได้ทอง · ❤️ ฟื้น HP · 💎 ดาเมจ +50%
- คำศัพท์เป้าหมาย ⭐ ได้ดาเมจ +50% และแสดงความหมายภาษาไทย บันทึกลงสมุดคำศัพท์
- คำยาว 4 ตัวขึ้นไปมีออร่า (ยิ่งยาวยิ่งเท่) และเสียงเวทมนตร์ไล่ระดับ
- คำธาตุ 9 แบบ (FIRE, ICE, STORM, WATER, POISON, WIND, ROCK, LIGHT, DARK ฯลฯ) มีคัตซีนมอบพลังให้อาวุธ: ติดไฟ แช่แข็ง ฟ้าผ่าซ้ำ ล้างหิน+ฮีล พิษ หลบหลีก ผิวหิน ฮีล ดูดเลือด
- คำหยาบใช้ได้ 🤬 ดาเมจ x2 แต่สะท้อนเข้าตัวเอง 30% ของ HP — so rude!
- คีย์บอร์ด: พิมพ์ตัวอักษร · Backspace ลบ · Enter โจมตี · Space สลับ · Esc หยุด

## 🌙 ใหม่ใน 2.0 (v21) — World & Progression Overhaul
เปลี่ยนโครงสร้างเกมจาก "หลายแท็บ" เป็น RPG ที่มี **ฐาน → โลก → ภารกิจ → การพัฒนา** เป็นแกนกลาง
โดยคงธีมมืดใต้แสงจันทร์ ม่วง/แดง/ทอง ภาพพิกเซล ตัวละคร ฟอนต์ Kanit และ **ระบบต่อสู้เดิมทั้งหมด**

- **เมนูหลักใหม่ 6 จุด:** 🏰 ฐาน · 🗺️ โลก · ⚔️ ฮีโร่ · 🎒 กระเป๋า · 📖 โคเด็กซ์ · 🏆 โปรไฟล์ (⚙️ ตั้งค่าเป็นปุ่มมุมขวาบน · 📜 ภารกิจเป็นปุ่มข้างๆ)
- **Hero Hub (Moonlit Haven):** ฉากฐานใต้แสงจันทร์ มีตัวละคร เลเวล ภารกิจปัจจุบัน ปุ่ม "ผจญภัยต่อ" ภารกิจประจำวัน คำแนะนำ "พัฒนาตัวละคร" และอาคารลัดไปทุกระบบ
- **World Map:** 5 พื้นที่ (Forgotten Cemetery · Star Meadow · Frozen Caverns · Flame Fortress · Necromancer's Grave) + Endless Tower เป็นพื้นที่พิเศษ แต่ละพื้นที่มีด่าน มินิบอส บอส ภารกิจ รางวัล ความคืบหน้า และสถานะปลดล็อก
- **Quest System:** ภารกิจหลัก 6 บท · ภารกิจเสริม 12 · Quest Chain 10 สาย (หลายขั้น) · ภารกิจประจำวัน 3 อย่าง/วัน (เปลี่ยนได้วันละ 1 ครั้ง + หีบโบนัส) · ติดตามภารกิจได้
- **Hero Sanctum:** ตัวละครเป็นศูนย์กลาง เลื่อน ‹ › หรือปัดซ้าย-ขวา · Level/EXP ของฮีโร่ · HP/ATK/DEF · สกิล · Ultimate · ธาตุ · อุปกรณ์ · Mastery · ฝึกฝน (อัปเกรดเดิม)
- **Inventory + Shop:** อาวุธ · เกราะ · ไอเทมเสริม · ไอเทม · วัตถุดิบ พร้อมปุ่ม SHOP ในกระเป๋า · วัตถุดิบใหม่ดรอปตามพื้นที่ ใช้ผสมยาหรือขาย
- **Quest Codex:** คำศัพท์ (Word Mastery: Level, Uses, Best Combo, Element) · มอนสเตอร์ · บอส · ฮีโร่ · ธาตุ · ตำนาน
- **Profile · Adventure Level · Trophy Room:** EXP จากทุกการเล่น → Adventure Level 1–50 พร้อมรางวัล (ทอง ไอเทม อาวุธ ฉายา กรอบรูป เอฟเฟกต์ที่ฐาน) · ถ้วยรางวัล 33 ใบ 4 ระดับความหายาก + ฉายาพิเศษ
- **Transitions:** สไลด์/ซูมระหว่างหน้า · ประตูมิติก่อนเข้าด่าน · หน้าผลการต่อสู้แสดง EXP วัตถุดิบ และภารกิจที่สำเร็จ · ปิดได้ในตั้งค่า
- **มือถือ:** เต็มจอ 100dvh ทุกหน้า · safe-area · แนวนอนแบ่ง 2 ฝั่ง · จอเล็ก 360px · โหมดเต็มจอ (Android/PC) · ติดตั้งเป็นแอปแบบ fullscreen
- **เซฟเดิมใช้ต่อได้ 100%:** ย้ายข้อมูลอัตโนมัติ (save.v2) และนับความคืบหน้าเดิมให้ย้อนหลัง (ด่าน คำศัพท์ ธาตุ มอนสเตอร์ที่เจอ → EXP/ภารกิจ/โคเด็กซ์)

### วิธีทดสอบเร็วๆ
1. `npm start` → เปิด http://localhost:3000 (เปิดโหมดมือถือใน DevTools เพื่อดูหน้าจอโทรศัพท์)
2. เซฟเดิม: เปิดเกมในเบราว์เซอร์เดิมที่เคยเล่น → จะเห็นข้อความต้อนรับ 2.0 และภารกิจที่ทำไว้แล้วรอรับรางวัล
3. ฐาน → "ผจญภัยต่อ" → ชนะด่าน → ดูหน้าผลลัพธ์ (EXP/วัตถุดิบ/ภารกิจ) → "กลับฐาน"
4. ลองทุกเมนูล่าง + ⚙️ ตั้งค่า + 📜 ภารกิจ · ปัดซ้าย-ขวาที่หน้าฮีโร่

## รันในเครื่อง
```bash
npm start
```
แล้วเปิด http://localhost:3000 (หรือดับเบิลคลิก `public/index.html` ก็เล่นได้)

## Deploy บน Vercel
1. Push โปรเจกต์ขึ้น GitHub
2. ใน Vercel → Add New Project → เลือก repo
3. Framework Preset: **Other** · Output Directory: **public** (มี `vercel.json` ตั้งไว้ให้แล้ว)
4. ไม่ต้องตั้ง Environment Variables
5. ทุกครั้งที่ `git push` Vercel จะ deploy ใหม่อัตโนมัติ

## โครงสร้าง
```
public/
  index.html          เกมทั้งหมด (HTML + CSS + JS + พจนานุกรม ในไฟล์เดียว)
  manifest.json       ตั้งค่า PWA
  service-worker.js   แคชให้เล่นออฟไลน์
  icons/              ไอคอนแอป
server.mjs            เซิร์ฟเวอร์ static สำหรับรันในเครื่อง
```
